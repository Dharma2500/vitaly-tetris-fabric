# Tetris by Vitaly_Sokolov

Классический Тетрис внутри Minecraft Java Edition.

- Minecraft: 1.21.11
- Mod loader: Fabric
- Mod ID: `vitaly_tetris`
- Java: 21
- Открытие игры: клиентская команда `/tetris`

## Игровые правила

- Поле 10 × 20, семь классических тетромино.
- Уровень повышается каждые 10 очищенных линий, максимум — 1000.
- Скорость растёт постепенно: от 900 мс до 180 мс на шаг падения.
- Очки начисляются за мягкий/мгновенный сброс и очистку линий.
- Комбо — последовательные ходы с очисткой линий.
- Следующие три фигуры показываются заранее.

## Управление

| Клавиша | Действие |
| --- | --- |
| ← / → | Перемещение |
| ↑ | Поворот |
| ↓ | Ускоренное падение |
| Пробел | Мгновенный сброс |
| Esc | Пауза и закрытие окна |

## Сохранения

Состояние партии и таблица лучших результатов хранятся локально в конфигурации Minecraft: `config/vitaly-tetris.json`.

## Сборка

Требуется JDK 21.

Windows:
```powershell
.gradlew.bat build
```

Linux / macOS:
```bash
./gradlew build
```

Готовый мод будет находиться в `build/libs` (JAR без суффикса `-dev`).
